为自托管而生的完整能力

从一个可执行文件到一套可编程的图片服务，该有的都有，不该有的没有。

三种上传方式

拖拽、批量选择、剪贴板粘贴均可上传；客户端可选自动转 WebP，多任务并发由页面级调度统一控速。

多格式引用一键复制

直链、HTML、Markdown、BBCode（含缩略图变体共 8 种）由服务端直接拼好，切 Tab 即取，论坛博客写作无缝衔接。

本地 + WebDAV 双存储

本地磁盘、远端网盘、双写备份三种模式运行时热切换；直链恒走本站代理，网盘真实地址与凭据绝不外泄。

完整 RESTful API

上传、列表、删除、统计、热配置全部开放，附 cURL / Python / Node 三种客户端示例与在线文档，curl 一行即可调用。

自动优化与秒传

Sharp 按 EXIF 转向、超尺寸缩放、再压缩，且负优化保护；动图保帧、SVG 保矢量；相同内容 sha256 秒传去重。

轻量管理台

登录后即可筛选、删除图片，修改站点名、游客限额、存储驱动等配置，改完即生效，全程无需重启进程。

Node.js ≥ 18 Express 4 SQLite Sharp 原生 HTML / CSS / JS Docker 多架构

两分钟部署到自己的服务器

无 ORM、无第三方鉴权库，克隆下来装好依赖就能跑。

本地直接运行

适合先体验：默认端口 3000，上传页 /，管理台 /admin

# 克隆并安装依赖
git clone https://github.com/muxin-403/lumina-image-hosting.git
cd lumina-image-hosting
npm install

# 启动服务
npm start

Docker 一条命令

多架构镜像（amd64 / arm64），数据落在 ./data 与 ./storage

# 拉取并启动（请替换管理员密码）
docker run -d --name lumina \
  -p 3000:3000 \
  -v "$PWD/data:/app/data" \
  -v "$PWD/storage:/app/storage" \
  -e ADMIN_PASSWORD='换成一个强密码' \
  ghcr.io/muxin-403/lumina-image-hosting:latest
